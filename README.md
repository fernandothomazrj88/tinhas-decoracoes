# Tinhas Decorações — Web V1

Site público + Tinhas Gestão.

## Publicação no GitHub Pages
A publicação deve usar a raiz (`/`) como pasta de origem.

- `index.html` = site público
- `style.css` = estilos do site
- `gestao/` = área de gestão (não é a área pública principal)

A URL final deverá ter o formato:
`https://SEU_USUARIO.github.io/tinhas-decoracoes/`
