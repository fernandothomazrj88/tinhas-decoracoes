# Tinhas Decorações — Site V2

Primeira evolução visual do site público.

O site é estático e está pronto para GitHub Pages. O conteúdo de portfólio usado agora é demonstrativo; depois será substituído por projetos reais e por dados publicados pelo Tinhas Gestão.

## Publicação
- `index.html` e `style.css` ficam na raiz do repositório publicado.
- GitHub Pages pode publicar a partir de `main` + `/ (root)`.

## Importante
O painel privado Tinhas Gestão não deve expor dados de clientes/financeiro em GitHub Pages. Vamos construir a interface privada dentro do Google Apps Script/HTML Service, usando `google.script.run`, enquanto o GitHub permanece como repositório do código e hospedagem do site público.
