# Tinhas Decorações — Web V1

Pacote inicial do ecossistema Tinhas.

## Estrutura

- `site/` — primeira vitrine pública.
- `gestao/` — primeira interface do Tinhas Gestão.
- `gestao/js/app.js` — consulta a API do Google Apps Script.
- `gestao/css/style.css` — identidade visual inicial.
